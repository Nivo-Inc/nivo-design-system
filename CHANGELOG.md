# Changelog

All notable changes to the Nivo Design System are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.2.0] - 2026-08-27

### Added

- Content-and-voice system for product, marketing, support, email, and AI-assisted experiences
- Approved terminology using “service provider” for a specific Nivo user
- Lucide-based icon system with visual, semantic, accessibility, motion, and custom-icon rules
- Machine-readable map of 58 verified Lucide icon names
- Lucide and Feather third-party license notices

### Changed

- Extended the visual documentation with content and icon examples
- Expanded source-of-truth and AI-collaborator guidance

### Verified

- Every mapped icon name exists in Lucide’s official library
- Locked master-logo geometry and checksum remain unchanged

## [1.1.0] - 2026-08-27

### Added

- GitHub-first visual documentation site for brand, foundations, components, examples, accessibility, downloads, and governance
- Responsive navigation and copyable foundation color values
- Repository contribution guidelines, pull-request template, ownership, and Pages deployment workflow
- Optional Figma import file while retaining GitHub as the source of truth

### Changed

- Connected the interactive component catalog to the design-system homepage
- Labeled the component library as version 1.1

### Verified

- Locked master-logo geometry and checksum remain unchanged
- Documentation supports reduced-motion preferences and a 320px minimum viewport

## [1.0.0] - 2026-08-25

### Added

- Approved Nivo brand direction and locked logo assets
- Foundation token files in JSON and CSS
- Brand, icon, and preview-board assets
- Framework-neutral component styles, behaviors, catalog, and specifications
- Visual design-system PDF
